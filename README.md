# li 语言编译器（前端）

li 是一门面向专业开发者的通用编程语言，使用中文关键字与中文符号，同时兼容英文写法。
本仓库实现编译器的第一个版本，当前阶段仅包含**前端**：词法分析、语法分析、基础语义检查与 CLI。

> 本阶段不包含 IR、字节码、虚拟机、运行时与垃圾回收。

## 目录结构

```text
.
├── Cargo.toml              # workspace 配置
├── LICENSE-MIT
├── LICENSE-APACHE
└── crates
    ├── li-errors           # 统一中文诊断、行列定位与源文件辅助
    ├── li-lexer            # 词法与 Token 定义（已实现）
    ├── li-ast              # AST 节点定义（已实现）
    ├── li-parser           # 递归下降语法分析器（已实现）
    ├── li-sema             # 语义分析与基础类型检查（骨架）
    └── li-cli              # 命令行入口（骨架）
```

## 构建与测试

```bash
cargo build --workspace
cargo test --workspace
```

所有 crate 均采用 `MIT OR Apache-2.0` 双协议。

## 统一诊断格式

`li-errors` 已经提供带行列号的中文诊断，例如：

```text
第 3 行第 5 列：类型不匹配，期望 整数，实际 字符串
```

错误信息同时支持期望值、实际值、稳定错误码和附注，词法、语法、语义三个阶段共用
`Diagnostic` 与 `DiagnosticBag`。

## 里程碑

1. **里程碑 1（已完成）**：初始化 workspace、六个 crate、双协议与 `li-errors` 基础定义。
2. **里程碑 2（已完成）**：定义 Token 与 AST 骨架，实现词法分析器，覆盖中文/英文关键字、全角/半角符号、
   `「」` 字符串、`#` 与 `#* ... *#` 可嵌套注释及行列定位。
3. **里程碑 3（已完成）**：实现递归下降解析器，表达式使用 Pratt 优先级攀升，
   语句级错误使用恐慌模式恢复到 `;` 或 `}`；覆盖变量、函数、结构体、模块、控制流、
   字段访问、下标、函数调用与 `成功` / `失败` 匹配语法，并通过斐波那契样例。
4. **里程碑 4**：实现符号表、不可变变量检查、函数签名与返回类型检查、基础类型匹配。
5. **里程碑 5**：接入 `li 解析 <file.li>` 与 `li 检查 <file.li>`，补充端到端测试与示例程序。
